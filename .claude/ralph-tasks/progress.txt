- New package src/training/adaptive/ (__init__.py, readiness.py, queries.py).
  - readiness.py = PURE functions/models (no DB, fully unit-tested):
    * Verdict(str,Enum): green/amber/red/insufficient_baseline.
    * build_hrv_baseline(values, min_points=28) -> HrvBaseline|None. x=ln(rMSSD), SAMPLE sd (n-1).
      Drops None/<=0 BEFORE the >=28 count. Returns None if insufficient -> caller falls back.
    * HrvBaseline props: lower_ln/upper_ln = mean -/+ 0.5*sd; red_threshold_ln = mean - 1.0*sd;
      low/high = exp() back to raw ms.
    * daily_verdict(today_hrv, baseline, *, secondary=None, prev_day_below_red=False).
      GREEN if ln(today)>=lower_ln; AMBER if <lower_ln; RED only if <red_threshold AND
      prev_day_below_red (2-day hysteresis — a single deep dip is AMBER, not RED).
      Secondary nudge: ONLY when borderline GREEN (today_ln<mean_ln, i.e. lower half of band)
      AND >=1 active flag -> AMBER. Never overrides RED, never downgrades a comfortable GREEN.
    * SecondaryModifiers.active_flags(): sleep<50, resting_hr>resting_baseline+5, TR<30.
  - queries.py = async DB (asyncpg pool.fetch/fetchval/fetchrow directly, no acquire needed).
    HRV value column is hrv_data.last_night_avg (overnight rMSSD avg). resting HR from
    daily_summary.resting_heart_rate; sleep_data.sleep_score; training_readiness.score.
    evaluate_daily_readiness(pool,user_id,day,persist=True) ties fetch->pure->upsert.
    fetchval call ORDER (matters for mock side_effect): today HRV, sleep, resting,

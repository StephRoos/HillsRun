## Project

HillsRun is a Python 3.13+ project managed with [uv](https://docs.astral.sh/uv/).

## Commands

- `uv run main.py` — run the application
- `uv add <package>` — add a dependency
- `uv sync` — install/sync dependencies from lockfile
